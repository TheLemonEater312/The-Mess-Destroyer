# The Mess Destroyer

### AI-Powered mess Detection System

## About the Project

The Mess Destroyer is a smart device designed to detect messy desks, shelves, and other surfaces using AI.

The goal is to help people keep their workspace organized by automatically identifying messy areas and sending notifications to their phone.

## How It Works

The planned system works in four steps:

1. A camera captures images of the place.
2. A Raspberry Pi Compute Module 5 processes the images using AI.
3. The software determines whether the workspace is messy or organized.
4. If mess is detected, the device sends a notification to the users phone.

## Hardware

The project uses or plans to use:

- Raspberry Pi Compute Module 5
- Raspberry Pi Camera Module 3 Wide
- Custom PCB designed in KiCad
- ESP32 for additional control and connectivity
- Waveshare UPS module
- Rechargeable batteries
- Small 5V cooling fan
- Electronic connectors and supporting components

## PCB Design

The custom PCB is being designed using KiCad.

The hardware design files and Bill of Materials will be available in this repository.

## Software

The planned software includes:

- Image capture
- AI-based mess detection
- Phone notifications
- Device configuration and monitoring

## Project Status

**In development**

## Project Goal

To create a compact, practical, and intelligent device that makes workspace organization easier through computer vision and automation.
